# Projeto de Teste de Software

Repositorio base para estudos, praticas e automacao de testes de software.

## Objetivo

Este projeto sera usado para:
- testes unitarios;
- testes de integracao;
- testes de API;
- validacao de requisitos;
- registro de evidencias e cenarios.

## Organizacao geral

O repositorio sera adaptado para conter:
- codigo de testes;
- massa de dados de apoio;
- documentacao de execucao;
- relatorios e evidencias.

## Como usar

1. Estruture os cenarios de teste.
2. Implemente os testes automatizados.
3. Execute a suite localmente.
4. Registre os resultados e falhas encontradas.
